# Hoop Land Save Menu

Instant in-browser editor for Hoop Land save files. Drop or paste a raw save, tap a preset (9999 coins, GOD TEAM, max roster, steal any player…), then **Copy raw save** and paste it into Hoop Land's import.

Everything runs locally in the browser — your save never uploads anywhere. Works offline once loaded.

Live: https://squasa.github.io/hoop-land-menu/
