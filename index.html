Publish to GitHub — get a fresh raw link for Hoop Land

Uploads your edited save as a new file in your GitHub repo, straight from this page. You get a raw download link to paste into Hoop Land. Old publishes stay as backups.

First-time setup (30 seconds, one time only)
  1. Open github.com/settings/personal-access-tokens/new
  2. Name it Hoop Land Menu, expiration 90 days
  3. Repository access → Only select repositories → pick hoop-land-menu
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token, copy it, paste it below and hit Save + test

The token is stored only in this browser on this device and is only ever sent to api.github.com. It can only touch this one repo.
